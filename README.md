# 《閒情記趣》配對遊戲

[立即遊玩｜GitHub Pages](https://loemily11451175.github.io/xianqing-matching-game/)

為香港中三級中國語文課堂設計的配對小遊戲。將六張「想像的事物」卡片配對至「所見的事物」，認識沈復筆下的物外之趣。

## 遊玩方式

- 用滑鼠或觸控拖動想像卡，放到對應事物上；也可先點選卡片，再點選答案格。
- 可用 Tab、Enter 或空白鍵進行配對，按 Escape 取消選取。
- 答對顯示「回答正確」及解說；答錯顯示「回答錯誤」，可無限次重試。
- 首次操作後開始背景音樂，頁頂可獨立開關音樂與答題音效。
- 所有六組選項與題目都在同一頁，完成後可回看答案或重新遊玩。

## 技術與部署

純 HTML、CSS、JavaScript 靜態網站，不需要安裝套件或建置。

GitHub Pages 發佈來源設為 `main` 分支的 `/(root)`。`.nojekyll` 讓 GitHub 直接發佈靜態檔案。所有圖片及程式路徑均為相對路徑，支援專案子目錄。

也可下載整個儲存庫，解壓縮後以瀏覽器開啟 `index.html`。

- `index.html`：頁面結構與文案
- `style.css`：樣式、動畫與響應式佈局
- `game.js`：配對互動、背景音樂與音效
- `assets/`：可愛手繪風格插畫

插畫由內建圖像生成工具製作；音樂及音效以 Web Audio 即時合成。網站沒有第三方前端套件、外部音樂串流或追蹤程式。
